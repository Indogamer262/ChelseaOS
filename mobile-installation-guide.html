0. Konfigurasi ADB (Phantom Process Fix)

Siapkan ADB (platform-tools) pada komputer Anda (PC Desktop, Laptop, Raspberry Pi, Orange Pi, dsb. yang terhubung ke jaringan lokal yang sama dengan ponsel target). Aktifkan USB/Wireless Debugging di Opsi Developer, lalu eksekusi perintah berikut:

adb shell "/system/bin/device_config set_sync_disabled_for_tests persistent"

adb shell "/system/bin/device_config put activity_manager max_phantom_processes 2147483647"

adb shell settings put global settings_enable_monitor_phantom_procs false

1. Persiapan APK

Unduh dan pasang APK pendukung yang diperlukan di ponsel Android Anda:

  • Termux (F-Droid)
  • Termux-X11 Releases
  • Termux:API (F-Droid)

Catatan: Anda dapat menginstalnya via ADB (adb install <file.apk>) atau metode sideloading. Pastikan untuk menonaktifkan optimasi baterai dan memberikan izin akses penyimpanan (MANAGE_EXTERNAL_STORAGE).

2. Persiapan Termux Environment

Buka aplikasi Termux di HP Anda, lalu jalankan perintah pembaruan paket dan instalasi Debian PRoot:

pkg update && pkg upgrade && pkg install x11-repo termux-x11-nightly pulseaudio wget proot-distro nano

Selanjutnya, pasang distribusi Debian:

proot-distro install debian

3. Persiapan PRoot-Distro Environment

Masuk ke dalam lingkungan container Debian:

proot-distro login debian

Pasang Desktop Environment XFCE4 & utilitas sudo:

apt update && apt upgrade && apt install xfce4 xfce4-goodies sudo

Buat pengguna baru bernama chelsea dan masukkan ke dalam grup sudo:

adduser chelsea sudo adduser chelsea sudo

Edit berkas sudoers dengan menjalankan nano /etc/sudoers, lalu tambahkan baris berikut di bagian bawah:

chelsea ALL=(ALL) NOPASSWD:ALL

4. Persiapan Desktop Environment

Kembali ke Termux dengan mengetik exit, lalu masuk kembali sebagai pengguna chelsea:

proot-distro login debian --user chelsea

Jalankan skrip transformer ChelseaOS Mobile untuk memasang tema dan konfigurasi otomatis:

wget -qO- resources/mobile/chelsea-mobile-transformer.sh | bash

Unduh manual: chelsea-mobile-transformer.sh

5. Persiapan Launcher

Kembali ke lingkungan Termux utama (ketik exit), lalu unduh dan beri izin eksekusi pada skrip launcher:

wget resources/mobile/start-chelsea.sh chmod +x start-chelsea.sh

Jalankan ChelseaOS Mobile menggunakan perintah berikut:

./start-chelsea.sh

Unduh manual: start-chelsea.sh

Chelsea Mobile Patcher Tools

Untuk memperbaiki masalah sandbox pada aplikasi berbasis Chromium/Electron (seperti Chromium, VS Code, Obsidian) di lingkungan PRoot, gunakan skrip patcher berikut di dalam Debian:

wget resources/mobile/chelsea-mobile-patcher.sh chmod +x chelsea-mobile-patcher.sh ./chelsea-mobile-patcher.sh

Unduh manual: chelsea-mobile-patcher.sh

Konfigurasi GPU Acceleration

Saat ini ChelseaOS Mobile 1.0 belum mendukung akselerasi GPU secara stabil. Jika Anda membutuhkan dukungan akselerasi GPU penuh, disarankan untuk menggunakan versi legacy NadineOS 5.1.
