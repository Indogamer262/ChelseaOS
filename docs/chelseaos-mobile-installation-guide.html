Guide to Install ChelseaOS Mobile in Termux Proot-Distro

0. Konfigurasi ADB

Siapkan ADB (platform-tools) pada komputer anda (bisa berupa apapun, PC Desktop, Laptop, Raspberry Pi, Orange Pi, ChelseaOS Mobile lain, dsb yang terkoneksi ke jaringan lokal yang sama dengan ponsel target). Aktifkan Debugging pada Opsi Developer, USB/Wireless Debugging, kemudian eksekusi:

adb shell "/system/bin/device_config set_sync_disabled_for_tests persistent"

adb shell "/system/bin/device_config put activity_manager max_phantom_processes 2147483647"

adb shell settings put global settings_enable_monitor_phantom_procs false

1. Persiapan APK

Download dan install APK yang diperlukan

  • Termux
  • Termux-X11
  • Termux:API

Anda dapat melakukan installasi melalui adb adb install <file.apk> atau manual melalui metode sideloading yang dapat diaktifkan di Developer Option, pilih aktifkan selamanya, lakukan verifikasi identitas, tunggu 24 jam. Kemudian buka Google Play Store, matikan Google Play Protect dan anda dapat menginstall APK tersebut. Jika anda menggunakan OneUI, silahkan nonaktifkan auto-blocker pada pengaturan keamanan dan privasi.

Setelah melakukan installasi, silahkan non-aktifkan battery optimalization dan berikan izin yang diperlukan, seperti MANAGE_EXTERNAL_STORAGE, dsb

2. Persiapan Termux Environment

Dalam lingkungan Termux eksekusi perintah berikut:

pkg update && pkg upgrade && pkg install x11-repo termux-x11-nightly pulseaudio wget proot-distro nano

Kemudian install distribusi untuk proot-distro

proot-distro install debian

3. Persiapan Proot-Distro Environment

Login ke dalam lingkungan proot-distro dengan mengeksekusi

proot-distro login debian

Kemudian persiapkan lingkungan dengan mengeksekusi perintah berikut:

apt update && apt upgrade && apt install xfce4 xfce4-goodies sudo

adduser chelsea
sudo adduser chelsea sudo

Pada berkas sudoers, untuk mengaksesnya gunakan nano /etc/sudoers, tambahkan baris berikut:

chelsea ALL=(ALL) NOPASSWD:ALL

4. Persiapan Desktop Environment

Silahkan kembali ke lingkungan Termux dengan mengetik exit, kemudian masuk kembali ke lingkungan proot-distro dengan mengeksekusi:

proot-distro login debian --user chelsea

Anda dapat menginstall software opsional ChelseaOS dengan mengeksekusi perintah berikut

wget -qO- https://content.christianah.my.id/chelsea-os/chelsea-mobile-transformer.sh | bash

Anda juga dapat secara manual mengunduhnya: chelsea-mobile-transformer.sh

5. Persiapan Launcher

Silahkan kembali ke lingkungan Termux dengan mengetik exit, kemudian anda dapat mengunduh skrip launcher dengan mengeksekusi:

wget https://content.christianah.my.id/chelsea-os/start-chelsea.sh

Atau secara manual mengunduhnya: start-chelsea.sh

Pastikan eksekusi diizinkan

chmod +x start-chelsea.sh

Kemudian berikutnya anda dapat menjalankan ChelseaOS Mobile dengan cara seperti ini:

./start-chelsea.sh

Chelsea Mobile Patcher Tools

Anda dapat mengunduh skrip Chelsea Mobile Patcher dengan mengeksekusi:

wget https://content.christianah.my.id/chelsea-os/chelsea-mobile-patcher.sh

Atau secara manual mengunduhnya: chelsea-mobile-patcher.sh

Konfigurasi GPU Acceleration

Saat ini ChelseaOS Mobile belum mendukung akselerasi GPU, untuk sementara, silahkan gunakan OS Legacy NadineOS 5.1 untuk akselerasi GPU
